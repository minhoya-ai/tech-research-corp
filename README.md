# 🌌 Aetheris AI Research Portal (테크/리서치 기업 홈페이지)

> **Pebblous AI(페블러스)의 세련된 다크 글래스모피즘 & 비주얼 데이터 아이덴티티를 벤치마킹하여 구축한 하이엔드 테크 & AI 연구 기업 공식 웹 포털**

본 프로젝트는 고차원 데이터 인텔리전스, 머신러닝 기초 연구, Physical AI 및 산업 표준 규제 대응을 선도하는 첨단 기술 연구소 / 딥테크 기업을 위한 풀스택형 웹사이트 템플릿이자 프로덕션 준비 완료 플랫폼입니다.

---

## ✨ 핵심 기능 및 설계 특징 (Pebblous AI 레퍼런스 반영)

### 1. 시각 디자인 & 인터랙션 시스템
- **동적 파티클 캔버스 배경 (`particles.js`)**:
  - 화면 마우스 인터랙션에 반응하여 별자리와 데이터 노드가 유기적으로 연결되는 캔버스 렌더러
  - 라이트/다크 테마에 따라 파티클 강도 및 색상이 실시간 동기화
- **다크 글래스모피즘(Glassmorphism) 테마**:
  - 딥 슬레이트 블랙 배경에 앰버/일렉트릭 오렌지 포인트 컬러(`--accent-gradient`) 적용
  - 상단 고정 투명 블러 헤더, 반투명 카드 테두리, 부드러운 호버 글로우 효과
- **실시간 다크/라이트 모드 지원**:
  - 원클릭 테마 전환 및 `localStorage` 브라우저 영구 보존

### 2. 콘텐츠 브라우징 & 뷰 제어
- **카드 뷰(Card View) ↔ 리스트 뷰(List View) 실시간 전환**:
  - 그리드 형태의 비주얼 카드와 컴팩트한 리스트 뷰를 버튼 클릭 한 번으로 즉시 전환
- **실시간 디바운스 검색 (단축키 `/`)**:
  - 키보드 `/` 키 입력 시 검색창으로 자동 포커스
  - 제목, 국/영문 요약, 저자, 키워드 해시태그 통합 실시간 검색
- **분야별 스마트 카테고리 칩 필터**:
  - `전체보기`, `AI 기초 연구`, `데이터 인텔리전스`, `피지컬 AI & 로보틱스`, `기술 백서 & 규제`
- **하이라이트 피처드 쇼케이스 배너**:
  - 대표 연구 논문/특허 성과를 상단에 와이드 배너로 하이라이트

### 3. 연구소 특화 기능 & 인터랙티브 랩
- **실시간 다차원 임베딩 & 데이터 진단 시뮬레이터 (Mini Lab)**:
  - 브라우저 상에서 고차원 벡터 클러스터링 생성 및 **Data Diet™ 정제 알고리즘** 실행 시연 가능
- **연구 성과 통계 모달 (Lab Metrics)**:
  - 총 논문 인용 수(16,400+), 보유 특허(19건), 엔터프라이즈 파트너(70+), ISO/IEC 5259 표준 규격 증빙
- **최근 열람한 연구 아티클 기록 (Reading History)**:
  - 사용자가 읽은 논문을 자동으로 로컬스토리지에 저장하여 언제든 다시 확인 가능
- **완전한 다국어(i18n) 지원**:
  - 한국어(KO) 및 영어(EN) 실시간 원클릭 전환 엔진

## 🚀 빠른 시작 (Getting Started)

### 1) 윈도우 원클릭 실행
프로젝트 폴더 내 **`start.cmd`** 파일을 더블클릭하면 자동으로 서버가 실행되고 기본 브라우저(`http://localhost:4000`)가 열립니다.

### 2) 터미널 명령어로 실행
```bash
# 종속성 설치
npm install

# 로컬 개발 서버 실행
npm start
# 또는 node server.js
```
브라우저에서 `http://localhost:4000`에 접속합니다.

```

├── package.json               # 프로젝트 설정 및 패키지 메타데이터

├── README.md                  # 프로젝트 설명서
└── public/                    # 프론트엔드 정적 리소스
    ├── index.html             # 메인 포털 마크업 (헤더, 히어로, 툴바, 모달)
    ├── css/
    │   └── theme.css          # 컬러 시스템, 다크/라이트 변수, 글래스모피즘
    └── js/
        ├── particles.js       # 배경 캔버스 파티클 네트워크 물리 시뮬레이션
        ├── data.js            # 회사 정보, 연구 논문, 메트릭 데이터 (KO/EN)
        ├── i18n.js            # 실시간 한/영 다국어 전환 엔진
        └── app.js             # UI 상태 관리, 검색, 뷰 전환, 모달, 인터랙티브 랩
```

## 🛠️ 커스터마이징 가이드

### 1. 회사명 및 연구소 정보 수정
`public/js/data.js` 파일의 최상단 `RESEARCH_DATA.company` 객체를 수정합니다:
```javascript
company: {
  name: "Your Tech Lab",
  koreanName: "당신의 테크 기업 연구원",
  tagline: "Your Vision Slogan Here",
  email: "contact@yourcompany.com"
}
```

### 2. 새로운 연구 논문 / 기술 블로그 추가
`public/js/data.js` 파일의 `RESEARCH_DATA.articles` 배열에 새 객체를 추가하기만 하면 웹페이지에 자동으로 반영됩니다.

### 3. 브랜드 테마 컬러 변경
`public/css/theme.css` 파일의 `:root` 섹션에서 주 포인트 컬러를 수정할 수 있습니다:
```css
:root {
  --accent-primary: #f97316;   /* 기본: 일렉트릭 오렌지 */
  --accent-secondary: #fb923c; /* 보조: 앰버 오렌지 */
}
```

## 🌐 외부 배포 방법

- **GitHub Pages / Vercel / Netlify (정적 호스팅)**:
  `public` 디렉토리 내용물만 정적 호스팅 서비스에 업로드하면 별도의 백엔드 없이도 모든 기능(검색, 뷰모드, 다국어, 시뮬레이터, 모달)이 100% 정상 작동합니다.
- **Node.js 서버 (AWS, GCP, VPS)**:
  `server.js`를 PM2 또는 Docker를 통해 프로덕션 포트(80 / 443)에서 배포할 수 있습니다.
